# Third-party components

EC Automatic News prepara o utiliza componentes de terceros. Revisa sus licencias antes de redistribuir una build pública:

- Electron — MIT
- llama.cpp — MIT
- Qwen3-8B-GGUF — Apache-2.0 (modelo descargado por el usuario desde Hugging Face)
- Kokoro model — Apache-2.0
- kokoro-onnx — MIT
- ONNX Runtime — MIT
- Python — PSF License

El workflow descarga los binarios/modelos desde sus proyectos oficiales durante el build o el primer uso.
